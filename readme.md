# Weather App

A weather application built with JavaScript that allows users to search for a location and view its current weather conditions. The app fetches weather data from an API and allows users to switch between Celsius and Fahrenheit.

## Features

- **Location Search:** Search for weather information by entering a location.
- **Weather Information:** View relevant weather data for the searched location.
- **Temperature Toggle:** Switch between Celsius and Fahrenheit.
- **Dynamic UI:** Display weather information based on the selected location.
- **Responsive Design:** A styled interface designed for a clean and user-friendly experience.

## Built With

- HTML5
- CSS3
- JavaScript (ES6+)
- Webpack
- Weather API

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd weather-app
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server using the appropriate script defined in `package.json`.

5. Open the application in your browser if it does not open automatically.

## Usage

1. Enter a city or location in the search field.
2. Submit the search to retrieve the weather information.
3. View the weather details displayed on the page.
4. Use the temperature toggle to switch between Celsius and Fahrenheit.
